How We Test

Rounds on the clock, scored, roles rotating

Rubric 7
  • Full 2:30 scored rounds, roles rotating.
  • Reliability tests: tried multiple times; must reach an 80% success rate.
  • Readiness check per role before the clock: many lost points were setup.
  • Documented each full game run on the whiteboard, and ingested weekly into the journal via Claude Code.
