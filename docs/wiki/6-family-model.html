6-Family Collaborative Model

Summary: Distributed coaching structure assigning each of six families a distinct role for the FLL season.

Sources: docs/FLL_Rookie_Team_Master_Roadmap.pdf

Last updated: 2026-05-11

Role Assignments

Role Responsibility
Technical Coach (A) Robot design & mechanical engineering
Coding Coach (B) Software logic, mission sequencing, debugging
Project Lead (C) Research, expert outreach, presentation coaching
Ops & Admin (D) Budget, registration, kits, official communication
Culture & Logistics (E) Snacks, Core Values team building, space setup
Media & Documentation (F) Engineering Notebook, photos, poster design

(source: FLL_Rookie_Team_Master_Roadmap.pdf)

Design Intent

Each family owns one lane — no overlap, no gaps. Reduces single-family burnout and ensures all FLL program areas (Robot Game, Innovation Project, Core Values) have dedicated adult support.

Key Interactions

  • Technical (A) + Coding (B) collaborate closely during 12 week season plan Phase 2 attachment and sensor work
  • Project Lead (C) drives expert interviews in Phase 2
  • Media (F) owns Engineering Notebook from Week 1 — must start immediately
