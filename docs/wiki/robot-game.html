Robot Game

Summary: Rules, structure, and strategy for the FLL robot competition portion of the event.

Sources: docs/IntrotoFLLSUBMERGED.pdf

Last updated: 2026-05-11

Setup

  • 4ft × 8ft table with a mat
  • All mission models are LEGO-based
  • Robot: LEGO MINDSTORMS or SPIKE Prime
  • New theme and mat layout each year (source: IntrotoFLLSUBMERGED.pdf)

Match Format

  • 3 rounds per competition; top score counts
  • 2.5 minutes per run to complete as many missions as possible
  • Referees score at the end of each run
  • Each mission has its own rules and point value
  • Harder missions are not always worth more points (source: IntrotoFLLSUBMERGED.pdf)

Missions

  • ~15 missions on the board each year
  • Teams pick which to attempt based on experience and ability
  • FIRST provides the solution to one mission per year to help rookies get started
  • Rookies expected to complete 2–3 missions reliably
  • Veteran teams complete more; top teams aim for all missions (source: IntrotoFLLSUBMERGED.pdf)

Common Challenges

  • LEGO Technic is often new material — teams must learn compact, sturdy builds
  • Teams tempted to copy robots online — FIRST encourages original design
  • Sensor navigation is hard for young teams
  • Reliability is the biggest struggle — robot behaves differently day-to-day or at event vs. practice (source: IntrotoFLLSUBMERGED.pdf)

Testing Protocol

  • Run each mission 10 times to measure reliability
  • Practice on varied conditions: shift mats, change tables, move mission models slightly
  • No two competition tables are alike — variability testing is essential (source: IntrotoFLLSUBMERGED.pdf)

2024-25 Season: SUBMERGED

Ocean-based theme. Mat shows underwater world with coral, whales, research vessels, and sample collection missions.

Gracious Professionalism at the Table

GP is observed and scored at the robot game table (separate from Robot Design judging). GP scores do not affect Robot Game score or rank. See gracious professionalism. (source: IntrotoFLLSUBMERGED.pdf)
